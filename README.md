# Ascent to the Stars

A xianxia cultivation game: rise from mortal clay through the realms, one breakthrough at a time.

## Play

- **In your browser:** [ascenttothestars.github.io/game](https://ascenttothestars.github.io/game/)
- **Home page:** [ascenttothestars.github.io](https://ascenttothestars.github.io/)
- **Wiki:** [ascenttothestars.github.io/wiki](https://ascenttothestars.github.io/wiki/)

## Download

- **Android:** [AscentToTheStars.apk](https://github.com/silvariasereneblossom/ascent-to-the-stars-releases/releases/latest/download/AscentToTheStars.apk)
- **Windows:** [AscentToTheStars-Setup.exe](https://github.com/silvariasereneblossom/ascent-to-the-stars-releases/releases/latest/download/AscentToTheStars-Setup.exe)
  (or the [.msi](https://github.com/silvariasereneblossom/ascent-to-the-stars-releases/releases/latest/download/AscentToTheStars.msi))

Install once. Every version updates itself after that, and your saves survive every update. Cloud Saves
(in the game's Config tab) keep your cultivators in step across the browser, Android and Windows.

## About this repository

This is the public mirror the game updates from. It is filled automatically by every release: `index.html`
is the whole game, `version.json` says which build is current, and the release holds the app installers.
Please don't open pull requests here; changes are made in the game's source and arrive with the next release.

The game's original browser address,
[silvariasereneblossom.github.io/ascent-to-the-stars-releases](https://silvariasereneblossom.github.io/ascent-to-the-stars-releases/),
still works, with its own separate saves.
